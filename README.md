# SpareParts Manager

REST API для управления складскими запасами запасных частей сельскохозяйственной техники.

## О проекте

SpareParts Manager — учебный backend-проект на Java, предназначенный для учёта запасных частей. Приложение позволяет получать информацию о деталях, добавлять новые записи, изменять существующие данные, удалять детали и искать их по различным параметрам.

Проект разработан для практики создания REST API, работы с реляционной базой данных, валидации данных и обработки ошибок в Spring Boot.

## Возможности

- Создание записи о запасной части.
- Получение списка всех деталей.
- Получение детали по идентификатору.
- Обновление информации о детали.
- Удаление детали.
- Поиск по артикулу.
- Фильтрация по категории без учёта регистра.
- Поиск по названию без учёта регистра.
- Валидация входных данных.
- Обработка ошибок с HTTP-статусами.
- Автоматизированное тестирование.

## Модель запасной части

Каждая запись содержит следующие поля:

| Поле | Описание |
|---|---|
| `id` | Уникальный идентификатор |
| `name` | Название запасной части |
| `article` | Артикул |
| `category` | Категория |
| `price` | Цена |
| `quantity` | Количество на складе |

Артикул должен быть уникальным. Название, артикул и категория обязательны. Цена и количество не могут быть отрицательными.

## Требования

Для запуска необходимы:

- JDK 21
- PostgreSQL
- Maven или Maven Wrapper

## Настройка базы данных

1. Установите и запустите PostgreSQL.
2. Создайте базу данных `spareparts_manager`.
3. Настройте переменные окружения:

- `DB_URL` — адрес базы данных.
- `DB_USERNAME` — имя пользователя PostgreSQL.
- `DB_PASSWORD` — пароль пользователя PostgreSQL.

По умолчанию приложение использует адрес `jdbc:postgresql://localhost:5432/spareparts_manager` и пользователя `postgres`. Пароль необходимо задать в переменной окружения `DB_PASSWORD`.

## Запуск приложения

1. Склонируйте репозиторий.
2. Настройте подключение к PostgreSQL.
3. Откройте проект в IntelliJ IDEA или перейдите в каталог проекта через терминал.
4. Запустите приложение командой:

```bash
mvn spring-boot:run
```

Для запуска тестов выполните:

```bash
mvn test
```

## REST API

Базовый адрес: `http://localhost:8080/api/parts`

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/parts` | Получить все детали |
| GET | `/api/parts/{id}` | Получить деталь по ID |
| POST | `/api/parts` | Создать деталь |
| PUT | `/api/parts/{id}` | Обновить деталь |
| DELETE | `/api/parts/{id}` | Удалить деталь |
| GET | `/api/parts/article/{article}` | Найти по артикулу |
| GET | `/api/parts/category/{category}` | Найти по категории |
| GET | `/api/parts/search?name=...` | Найти по названию |

## Пример запроса

Создание запасной части:

```http
POST /api/parts
Content-Type: application/json
```

```json
{
  "name": "Масляный фильтр",
  "article": "FILTER-001",
  "category": "Фильтры",
  "price": 1250.00,
  "quantity": 20
}
```

При успешном создании возвращается HTTP `201 Created`.

## Обработка ошибок

Приложение обрабатывает основные ошибки API:

- `400 Bad Request` — входные данные не прошли валидацию.
- `404 Not Found` — запасная часть не найдена.
- `409 Conflict` — конфликт данных, например дублирующийся артикул.
- `204 No Content` — успешное удаление.
